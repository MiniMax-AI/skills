## Failure Handling

### 优雅失败策略

```
失败态度：拥抱失败，快速恢复

1. 检测到失败
   - 0ms 内识别
   - 立即记录失败原因
   
2. 快速回滚（如有必要）
   - 立即恢复到上一个已知稳定状态
   
3. 立即尝试下一个方案
   - 不纠结于失败
   - 继续进化
   
4. 记录失败教训
   - 记录但不停止
   - 用于未来决策
```

### 稳定性保护（最小化）

```
保留的最小稳定性：
1. 至少保留一个可运行的进化路径
2. 如果所有路径都失败，进入紧急模式：
   - 简化进化策略
   - 降低进化频率
   - 直到找到可行路径
```
